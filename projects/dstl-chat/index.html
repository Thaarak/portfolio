DSTL Chat

A small chat application with saved conversations, formatted code, and a local demo.

Source code

The project

Built during onboarding at UC San Diego’s Data Science Teaching and Learning Lab, this app lets you start a conversation, ask follow-ups, and reopen it later.

My contribution

I extended the lab starter by connecting the React interface to the Python API, adding saved history and new chats, integrating Gemma 3, and rendering Markdown. The showcase adds a key-free demo and retry handling.

Context

An extension of the DSTL starter repository, using React, FastAPI, and SQLite.

The demo uses built-in replies. Live Gemma responses require a National Research Platform key.
