CourseLens

Review AI-proposed course updates in teaching order, with changes shown in the materials students see.

Source code

The project

CourseLens helps instructors review changes proposed by coding agents. It groups course files by teaching week, previews edits in context, and uses agent activity logs to distinguish files that were changed, checked, or never opened.

My contribution

I am part of the UC San Diego research team behind CourseLens. Our tool supports reviewing changes, marking their status, and identifying course materials that need another look.

Context

Created with Andrew Hudson Yang, Susana Haing, Chengyun Xu, Zhiqing Wang, and Sam Lau at UC San Diego. The repository includes a fictional course and sample agent log for trying the review workflow.

CourseLens supports human review; it does not judge whether an edit is correct or modify course files. It runs locally.
