Arnold

A fitness journal that turns a description of a meal or workout into an entry you can review.

Source code

The project

Describe what you ate or how you trained, check what Arnold understood, then save the entry. The public showcase includes a food and exercise catalog and keeps journal entries in the browser.

My contribution

I extended the team’s hackathon prototype with plain-English meal and workout tracking, USDA food lookup, exercise search, and voice interaction. For the showcase, I rebuilt the review-and-save flow, portion conversion, and mobile layout.

Context

The original prototype was built with Shrish, Kenny, and Jello at the MCP AI Agent Hackathon in July 2025. The public repository credits additional contributors.

Nutrition values are estimates. The local demo needs no API keys; live integrations are optional.
