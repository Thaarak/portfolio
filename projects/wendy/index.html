Wendy

A wedding-planning workspace for venue shortlists, inquiry drafts, and guest RSVPs.

Source code

The project

Wendy keeps venue search, guest lists, and planning conversations together. You can set a budget and guest count, shortlist venues, and draft an inquiry using the details already in the conversation.

My contribution

I built the venue-search tool, connected it to chat, and implemented the reservation-request workflow that collects event details and drafts an inquiry. I also added a self-contained showcase and a mobile layout.

Context

Original team: Thaarak Sriram, Shrish Premkrishna, Aryaman Gandhi, and Kenny.

The demo runs locally with fictional data. It does not send email or make bookings.
